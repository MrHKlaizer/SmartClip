### Что нового
- **Автозахват записей и аудио из нескольких папок.** Папки можно выбрать самому, стандартные (клипы Xbox Game Bar, «Записи экрана», «Звукозаписи») находятся автоматически. Видео появляются в колонке картинок, аудио — в колонке текстов. Клик по карточке вставляет файл.
- **Экспорт и импорт настроек** теперь переносит и оформление: скорости анимаций, вид прокрутки, шкалу дат, тёмный фон.

### Улучшения
- После копирования окно открывается быстрее: добавляются только новые записи.
- Быстрый поиск даже по большой истории.
- Шкала дат стала тоньше и больше не затемняет карточки.
- Описание обновления показывается, даже если GitHub временно ограничил запросы.

### Исправления
- Мелкие исправления и чистка кода.

### What's new
- **Auto-capture of recordings and audio from several folders.** Choose the folders yourself; the standard ones (Xbox Game Bar clips, "Screen Recordings", "Sound Recordings") are found automatically. Videos appear in the images column, audio in the texts column. Click a card to paste the file.
- **Settings export and import** now also carries the appearance: animation speeds, scrolling style, date scale, dark background.

### Improvements
- The window opens faster after copying: only new entries are added.
- Fast search even in a large history.
- The date scale is thinner and no longer dims the cards.
- Update notes are shown even when GitHub temporarily limits requests.

### Fixes
- Small fixes and code cleanup.

### Neu
- **Automatische Erfassung von Aufnahmen und Audio aus mehreren Ordnern.** Die Ordner lassen sich selbst wählen, die Standardordner (Xbox-Game-Bar-Clips, „Bildschirmaufnahmen“, „Tonaufnahmen“) werden automatisch gefunden. Videos erscheinen in der Bilderspalte, Audio in der Textspalte. Ein Klick auf die Karte fügt die Datei ein.
- **Export und Import der Einstellungen** übernehmen jetzt auch die Darstellung: Animationsgeschwindigkeiten, Scroll-Stil, Datumsskala, dunkler Hintergrund.

### Verbesserungen
- Nach dem Kopieren öffnet sich das Fenster schneller: Es werden nur neue Einträge hinzugefügt.
- Schnelle Suche auch in einem großen Verlauf.
- Die Datumsskala ist schmaler und dunkelt die Karten nicht mehr ab.
- Update-Hinweise werden auch angezeigt, wenn GitHub Anfragen vorübergehend begrenzt.

- Kleine Korrekturen und Aufräumen des Codes.
