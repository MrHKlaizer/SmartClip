### Исправления
- Карточки в колонках иногда оставались сдвинутыми вбок (как у края экрана), хотя стояли посередине. Теперь они всегда возвращаются на место.

### Улучшения
- SmartClip понимает версии из четырёх чисел (например, 2.2.3.1) — для будущих мелких исправлений.

<a name="lang-en"></a>
### Fixes
- Cards in the columns sometimes stayed shifted sideways (as if at the screen edge) even in the middle. They now always return to their place.

### Improvements
- SmartClip understands four-part versions (e.g. 2.2.3.1) — for future small fixes.

<a name="lang-ua"></a>
### Виправлення
- Картки в колонках іноді лишалися зсунутими вбік (як біля краю екрана), хоча стояли посередині. Тепер вони завжди повертаються на місце.

### Покращення
- SmartClip розуміє версії з чотирьох чисел (наприклад, 2.2.3.1) — для майбутніх дрібних виправлень.

<a name="lang-de"></a>
### Fehlerbehebungen
- Karten in den Spalten blieben manchmal seitlich verschoben (wie am Bildschirmrand), obwohl sie in der Mitte standen. Jetzt kehren sie immer an ihren Platz zurück.

### Verbesserungen
- SmartClip versteht vierstellige Versionen (z. B. 2.2.3.1) — für künftige kleine Korrekturen.
