### Исправления
- Обновления с номером из четырёх чисел (например, 2.2.3.1) не находились — SmartClip считал себя актуальным. Теперь находятся.
- При переносе на другой монитор окно больше не мелькает целиком перед анимацией открытия.
- Вкладка настроек «Дополнительно» теперь называется «Инфо», без плашки про бета-функции.

Всё из 2.2.3.1 тоже здесь:
- При первой установке экран мог стать тёмным (без панели задач) до перезагрузки — из-за перезапуска Проводника. Теперь Проводник перезапускается правильно, а если это невозможно — не трогается вовсе.
- Полоска файлов больше не сворачивается при переключении на вкладку, где файлов меньше.
- Значки файлов: у Word снова значок с «W», у ZIP и PDF нет светящейся каймы.
- Два монитора: горячая клавиша переносит SmartClip на монитор с мышью, а не просто закрывает.
- Пустые плитки-заглушки там, где нет файлов; значки в свёрнутой полоске идут слева направо.

<a name="lang-en"></a>
### Fixes
- Updates with a four-part number (e.g. 2.2.3.1) were not found — SmartClip thought it was up to date. Now they are found.
- When moving to another monitor, the window no longer flashes fully before the open animation.
- The "Advanced" settings tab is now called "Info", without the beta banner.

Everything from 2.2.3.1 is included too:
- On first install the screen could go dark (no taskbar) until a reboot — caused by restarting Explorer. Explorer is now restarted correctly, and if that is not possible it is left alone.
- The files strip no longer closes when switching to a tab with fewer files.
- File icons: Word shows the "W" icon again, ZIP and PDF have no glowing fringe.
- Two monitors: the hotkey moves SmartClip to the monitor with the mouse instead of just closing it.
- Empty placeholder tiles where there are no files; icons in the collapsed strip go left to right.

<a name="lang-ua"></a>
### Виправлення
- Оновлення з номером із чотирьох чисел (наприклад, 2.2.3.1) не знаходилися — SmartClip вважав себе актуальним. Тепер знаходяться.
- Під час перенесення на інший монітор вікно більше не блимає повністю перед анімацією відкриття.
- Вкладка налаштувань «Додатково» тепер називається «Інфо», без плашки про бета-функції.

Усе з 2.2.3.1 теж тут:
- Під час першого встановлення екран міг стати темним (без панелі завдань) до перезавантаження — через перезапуск Провідника. Тепер Провідник перезапускається правильно, а якщо це неможливо — не чіпається зовсім.
- Смужка файлів більше не згортається під час переходу на вкладку, де файлів менше.
- Значки файлів: у Word знову значок із «W», у ZIP і PDF немає світної кайми.
- Два монітори: гаряча клавіша переносить SmartClip на монітор із мишею, а не просто закриває.
- Порожні плитки-заглушки там, де немає файлів; значки у згорнутій смужці йдуть зліва направо.

<a name="lang-de"></a>
### Fehlerbehebungen
- Updates mit vierstelliger Nummer (z. B. 2.2.3.1) wurden nicht gefunden — SmartClip hielt sich für aktuell. Jetzt werden sie gefunden.
- Beim Wechsel auf einen anderen Monitor blitzt das Fenster vor der Öffnungsanimation nicht mehr vollständig auf.
- Der Einstellungs-Tab „Erweitert“ heißt jetzt „Info“, ohne Beta-Hinweis.

Alles aus 2.2.3.1 ist ebenfalls enthalten:
- Bei der Erstinstallation konnte der Bildschirm bis zum Neustart dunkel werden (ohne Taskleiste) — durch den Neustart des Explorers. Der Explorer wird jetzt korrekt neu gestartet; ist das nicht möglich, bleibt er unangetastet.
- Die Dateileiste klappt beim Wechsel zu einem Tab mit weniger Dateien nicht mehr zu.
- Dateisymbole: Word zeigt wieder das „W“-Symbol, ZIP und PDF ohne leuchtenden Rand.
- Zwei Monitore: Das Tastenkürzel verschiebt SmartClip auf den Monitor mit der Maus, statt es nur zu schließen.
- Leere Platzhalter-Kacheln, wo keine Dateien sind; Symbole in der zugeklappten Leiste laufen von links nach rechts.
